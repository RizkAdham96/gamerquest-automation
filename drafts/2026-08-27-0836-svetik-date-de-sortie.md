## Article

<p>Le trailer officiel de <strong>Svetik</strong> annonce une sortie le <strong>25 août</strong> sur PC via Steam, avec une démo téléchargeable dès maintenant.</p>

<h2>Quelle est la date de sortie de Svetik ?</h2>
<p>Le trailer officiel indique que la sortie prévue de <em>Svetik</em> est le <strong>25 août</strong>. Aucun autre jour n’a été communiqué.</p>

<h2>Sur quelles plateformes le jeu sera‑t‑il disponible ?</h2>
<p>AEVI Studio a confirmé que le titre sera disponible uniquement sur <strong>PC (Steam)</strong> à la date annoncée. Aucune version console n’a été mentionnée.</p>

<h2>Quel sera le prix de Svetik ?</h2>
<p>À ce jour, le studio n’a pas communiqué de prix officiel. Les informations tarifaires seront probablement révélées plus près de la sortie.</p>

<h2>À quoi ressemble le gameplay ?</h2>
<p><em>Svetik</em> est un <strong>aventure‑RPG 2D top‑down</strong> à l’atmosphère sombre. Le joueur incarne une jeune fille amnésique accompagnée d’une étincelle de lumière vivante, qui sert d’arme. Le jeu mise sur la gestion de la confiance avec ce compagnon lumineux ; perdre cette confiance plonge le joueur dans une obscurité totale pendant les combats.</p>

<h2>Le jeu proposera‑t‑il du multijoueur ?</h2>
<p>Le trailer et les informations officielles ne font aucune mention d’un mode multijoueur. Le titre semble donc être une expérience <strong>solo</strong> uniquement.</p>
